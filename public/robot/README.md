# Johnny Five Robot Asset Pipeline

This folder is for the new rigged humanoid robot pipeline.

Do not overwrite original Tripo exports. Keep downloaded FBX files unchanged in `original_tripo_exports/` so there is always a clean source copy.

Add downloaded FBX files to `original_tripo_exports/`.

Later conversion and optimization output should go in `processed/`. Runtime-ready GLB or glTF files will live there after inspection and conversion.

Screenshots, contact sheets, and visual review images should go in `previews/`.

The old tracked/sprite artwork pipeline is archived separately under `archive/old-johnny-five-artwork-2026-06-07/`.
