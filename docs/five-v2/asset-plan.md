# Five V2 Asset Plan

All future V2 puppet assets must derive from the approved master reference:

`src/assets/five-v2/reference/five-v2-master-reference.png`

Do not crop, slice, animate, or integrate the master reference image directly. It is a visual reference only.

## Phases

### Phase 1: Base and Tread Parts Only

Generate and approve the base and tread components that match the approved master reference.

### Phase 2: Head, Eyes, Lenses, and Neck Only

Generate and approve the binocular head assembly, amber lenses, eyelid/brow details, and mechanical neck/head support.

### Phase 3: Torso, Toolbox, Arms, Grippers, and Lights Only

Generate and approve the compact boxy torso, left-shoulder red toolbox, manipulator arms, claw/gripper hands, and warm amber body indicator lights.

### Phase 4: Tread Animation Frames Only

Generate tread animation frames only after the static tread design is approved.

### Phase 5: Final Approved Puppet Kit Assembly

Assemble the final puppet kit only after all prior phases are approved and visually consistent with the master reference.

## Transparency Note

The checkerboard background in the master reference is acceptable for reference only. Production puppet assets must be true transparent PNG files.
