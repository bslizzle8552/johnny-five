# Five V2 Master Reference

The most recently generated full-body robot image is the approved V2 master character reference for character 5.

Approved reference file:

`src/assets/five-v2/reference/five-v2-master-reference.png`

This image is reference only. It must not be used as a full-body app sprite, sliced into puppet parts, animated directly, or treated as a production puppet asset.

## Locked Design Traits

- Wide tracked mobility base
- Twin camera-eye head
- Large amber expressive lenses
- Compact boxy torso
- Visible mechanical neck/head support
- Small manipulator arms
- Claw/gripper hands
- Red toolbox mounted on the robot's left shoulder
- Warm amber body indicator lights
- Worn white and dark metal panels
- Exposed cables, pivots, and mechanical joints
- Friendly, curious, intelligent, non-threatening workshop robot personality

## Asset Derivation Warning

The V2 puppet assets must be derived from this approved master reference.

Do not create generic robot parts.
Do not mix inconsistent robot designs.
Do not use the old V1 sprite.
Do not use rejected V2 asset batches.
Do not use random image-generated parts that do not match this master reference.

The checkerboard background in the master reference is acceptable for reference only. Production puppet assets must be true transparent PNG files.
