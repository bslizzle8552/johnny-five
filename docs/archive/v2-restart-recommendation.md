# Johnny Five V2 Restart Recommendation

Johnny Five V2 should start as a new clean project or clean branch.

V2 should not import the old character implementation.

Recommended V2 order:

1. Approve a new master character design that still clearly feels like Johnny 5.
2. Create exact puppet parts from that approved design.
3. Build a blank PuppetLab stage.
4. Assemble the puppet from transparent PNG parts.
5. Prove idle life first.
6. Prove stationary tread animation.
7. Prove grounded rolling.
8. Prove turning.
9. Only then bring back charger, workshop, speech, AI, voice, or other features.

The next milestone is asset approval, not animation.
