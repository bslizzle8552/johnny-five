# Johnny Five V1 Lessons Learned

1. Do not build the new version around the old full-body robot image.
2. Do not chop up one static image and call it a puppet.
3. Do not fake tread motion with blur boxes, black rectangles, overlays, or smears.
4. Do not make the charger central before the robot itself works.
5. Do not work on workshop polish until the character feels alive.
6. Do not let Codex reuse legacy assets as fallbacks.
7. Do not proceed without approved puppet assets.
8. Do not treat asset generation sheets as production assets unless every part clearly belongs to the same robot.
9. The next project should begin with an approved master character design.
10. The next project should then create real transparent PNG puppet parts from that exact design.
